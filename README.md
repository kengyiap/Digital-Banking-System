# Digital Banking System (Java OOP)

A console-based academic digital banking system built with **Java** for the Object-Oriented Programming Techniques course. This repository contains the **NetBeans/Ant** project source code.

## Features
- Customer registration, login and profile management
- Savings and current accounts, with account requests and approvals
- Deposits, withdrawals and transfers
- Transaction history and bank statement generation
- Admin management of accounts, customers, and reports
- Savings interest and current account overdraft features

## Technologies
- Java (Object-Oriented Programming)
- Apache NetBeans / Apache Ant
- CSV-based local file persistence (generated while running)

## Project structure
- `src/digitalbankingsystem/` — 9 Java source files
- `build.xml` — NetBeans Ant build file
- `nbproject/` — project configuration (excluding machine-specific private settings)
- `screenshots/` — add your own program screenshots here

## How to run
1. Open the folder as an existing project in Apache NetBeans (with Java and Ant available).
2. Build and run the project; entry point: `digitalbankingsystem.Main`.
3. The application uses a text-based menu in the console.
4. Local CSV data files are generated or updated as the application runs. These are intentionally excluded from the public repository.

## Note for reviewers
This is an **educational demo**, not a production-ready financial application. Source code includes a simple demonstration admin login, and customer passwords are handled without production-grade protection. Do not use real personal information or passwords when testing.
